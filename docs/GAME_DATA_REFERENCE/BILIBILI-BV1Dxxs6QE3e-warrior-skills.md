## 重点摘要

1. **开天斩断层最强**：0~3 级伤害倍率 106% / 160% / 212% / 266%，直线 4 格；另有默认 **10% 概率重击、重击倍率 130%**，3 级理论峰值 **266% × 1.3 = 345.8%** 一刀。很多服还继续加数值或加无视魔法盾，这是"被开天一刀秒"的原因。
2. **刺杀是战士灵魂技能**：0~3 级 40% / 60% / 80% / 100%，打**身前第二格且无视防御**，百分比只与自身攻击力发挥有关。
3. **攻杀是固定伤害**：0 级额外 5 点固伤，之后每级 +1 准确与 +1 点固伤；固伤**不受攻击、幸运、诅咒影响**，触发概率随等级升高，且因伪随机可用"放空刀"确保下一刀必触发。
4. **半月剑气与主目标解耦**：0~3 级 15% / 25% / 31% / 38%，额外打身边 3 个敌人；会计算目标防御，但**主目标不破防也不影响剑气打旁边的小怪**。
5. **逐日是数据最弱的进阶技能**：0~3 级 53% / 80% / 106% / 133%，直线 4 格、无视距离、无特效；UP 明确说"不存在距离远打得更疼"，且很多版本会自行加强。
6. **烈火 0 级甚至不如平砍**：0~3 级 56% / 108% / 176% / 260%；1 级起才超过 100%。
7. **基本剑术只加准确**：0 级无效，1/2/3 级分别 +3/+6/+9 准确。

### 逐项机制说明

- **基本剑术**：视频原话"根据等级加准确，0 级没效果，1 级加 3 准确，2 级加 6 准确，三级加 9 准确；有准确战士才能打得中人。"
- **攻杀剑术**：
  - 画面表格：`0级：触发5点固伤 / 1级：准确+1，6点固伤 / 2级：准确+2，7点固伤 / 3级：准确+3，8点固伤`；字幕补充"0 级可造成额外 5 点固定伤害"。
  - "攻杀造成的伤害是固定伤害，不受攻击、幸运、诅咒等影响。"
  - "具体触发概率没详细测试，但从测试过程中的感觉上是等级越高触发概率越高。"
  - "因为这个概率用的伪随机，兄弟们 3 级攻杀可以通过放空刀来确保下一刀命中目标必定触发攻杀。"
- **刺杀剑术**：
  - "对身前第二格造成无视防御的伤害，可以说是战士的灵魂技能之一。"
  - "不过多少级刺杀都是对刺杀格无视防御，0 级刺杀只造成 40% 伤害，1 级 60%，2 级 80%，3 级 100% 伤害，只跟自身攻击力发挥有关。"
- **半月弯刀**：
  - "可挥出剑气对身边额外三个敌人造成伤害：0 级 15%，1 级 25%，2 级 31%，3 级 38%。不要觉得 31% 和 38% 数字奇怪，测试下来就是这个数字。"
  - "半月的伤害跟人物攻击发挥是有关的，也会计算被击中的目标的防御，但是跟主目标无关；哪怕你打主目标都不破防，半月剑气一样能对旁边的小怪造成伤害。"
- **野蛮冲撞**：UP 未测伤害，认为更多涉及使用技巧，技能本身数据不是很重要。
- **烈火剑法**：UP 再次强调本次是 996 引擎官方表单数据；"零级烈火 56% 的伤害，对的没错，零级烈火不如你自己平砍；一级 108%，两级 176%，三级 260%。"
- **逐日剑法**："一条线四个格子伤害，无任何特殊效果，不存在距离远打得更疼的说法"；数据 53% / 80% / 106% / 133%；"这数据看起来是真的弱，很多版本都是将这个技能伤害加强了的。"
- **开天斩**：
  - "不愧是英雄专属技能，强就一个字。首先是一条直线 4 个格子伤害：0 级 106%，1 级 160%，2 级 212%，3 级 266%。"
  - 技能面板截图（`开天斩 / 刺杀剑法 / 逐日剑法` 页签）：攻击力倍数 `100 / 100`；重击设置：重击几率 `10`，重击攻击力倍数 `130 / 100`。
  - "默认是 10% 几率重击，重击时技能造成 30% 额外伤害，也就是最高 345.8% 一刀的伤害，而且这还是默认伤害；很多版本里面这个技能还设置了忽视魔法盾、调高伤害数值。"

### 未测 / 不确定项

- 攻杀剑术的具体触发概率（UP 只给"等级越高越高"的体感，没有量化）。
- 幸运 / 诅咒对攻杀固伤的量化影响（只说了"不受影响"）。
- 野蛮冲撞的伤害数据与技巧细节。
- 各私服魔改后的技能数值（本视频只测零改动环境）。

## 调优参考提示

- 本项目若走**原版保真**路线，可把「刺杀第二格无视防御」「半月与主目标防御解耦」「攻杀为固定伤害」列为行为核对清单，但**数值不能直接照搬**；改数值前先按项目 skill 找原版依据。
- 若要解释"战士一刀秒人"，优先检查**开天斩重击叠乘链**（技能面板倍率 × 重击 130%），以及私服常见的无视魔法盾配置；345.8% 可作为爆发倍率的上界参考。
- 「逐日偏弱」是 996 官方表单的表现，**不要因为看起来弱就直接加强**；私服加强属于魔改，需先确认项目目标版本。
- 项目实现索引（仅定位，不代表数值一致）：`pyserver/handlers_combat.py`（伤害结算、刺杀/半月副目标）、`pyserver/world.py`（技能开关与命中修炼）、`pyserver/autopilot.py`（托管自动开关）。
- 后续可补测项：攻杀触发概率、空刀技巧的可复现性、幸运/诅咒与固伤的关系。
