**测试口径（UP 主口述）**：

- **以热血传奇官服法师数据为准**，并多处对比「私服/盛大」（原文口播为「圣大和斯福」，即盛大和私服）。
- 伤害数值建立在**幸运 9**、目标**魔御 0** 的基础上；法师即使幸运 9，伤害仍有波动（与战士不同）。
- 数值为「技能伤害加成」口径，通常不含人物魔法力；含魔法力时口播会另作说明。
- 本视频针对**法师 14 个技能**，分伤害技能（单体/直线/群体）与特殊技能两类。

## 重点摘要

1. **等级门槛与项目 `Magic.csv` 完全一致**：14 个技能的学习/二重/三重等级逐项吻合，说明视频讲的就是经典 1.76/1.80 `Magic.DB`，与项目同一数据源。
2. **对怪倍率方向与原版相反（P0）**：原版 `ObjBase.pas:7403` 对 `RaceServer >= RC_ANIMAL` 的目标是 **×1.2**（怪比玩家多掉血），项目实现成 **÷1.2**。视频原话也印证「官服怪掉血比玩家多，私服相反」。
3. **疾光电影 1.5 倍被写成逐目标累乘（P0）**：原版 `MagPassThroughMagic` 里 `acpwr := Round(magpwr * 1.5)`，`magpwr` 是值参数不变，**每个目标固定 1.5 倍**；项目在循环里累乘，第 n 个目标变成 1.5ⁿ。
4. **魔法盾项目取的是私服值**：项目 16/24/32/40%（= 火炬 `(等级+2)×8`，与视频「私服」一栏完全一致）；官服是 15/30/45/60%。这是版本差异，不是 bug。
5. **诱惑之光宝宝数量**：官服 0 级 2 只、一重 3 只、二重 4 只、三重 5 只；项目 `summon_id` 单值，只支持 1 只。

## 与项目实现对比

### P0：与原版不符（建议修）

**1. `RM_DELAYMAGIC` 对怪倍率方向反了**

- 原版（火炬 `ObjBase.pas:7400-7407`）：
  ```pascal
  n := target.GetMagStruckDamage (self, magpwr);   // 先扣 MAC / 过魔法盾
  if n > 0 then begin
     if target.RaceServer >= RC_ANIMAL then
        magpwr := Round(magpwr * 1.2);             // 再对动物/怪物 ×1.2
     ...
  ```
- 项目（`pyserver/handlers_combat.py:1197`）：
  ```python
  pwr = delphi_round(pwr / 1.2) if getattr(target, "race", 0) >= RC_ANIMAL else pwr
  dmg = mag_struck_damage(target, pwr)
  ```
- 差异：**方向相反**（1.2 vs 0.833），且**顺序相反**（原版先扣 MAC 再 ×1.2）。
- 影响技能：火球术、大火球、雷电术、灵魂火符（所有走 `RM_DELAYMAGIC` 的）。
- 综合偏差约 **1.44 倍**（0.833 vs 1.2），对怪伤害只有原版的 ~69%。
- 视频佐证：官服「怪掉血比玩家多」，私服相反；项目目前是私服行为。

**2. 疾光电影 ×1.5 被写成逐目标累乘**

- 原版（`ObjBase.pas:7126`）：
  ```pascal
  if undeadattack then
     acpwr := Round (magpwr * 1.5)    // magpwr 是值参数，每格都算同一个 1.5 倍
  ```
- 项目（`pyserver/handlers_combat.py:866-867`）：
  ```python
  if undead_attack:
      cur_pwr = delphi_round(cur_pwr * 1.5)   # cur_pwr 在循环内累乘
  ```
- 差异：原版每个目标固定 ×1.5；项目第 n 个目标 ×1.5ⁿ（第 3 个 3.375 倍、第 5 个 7.6 倍、第 8 个 25.6 倍）。
- 视频口径也是「固定 1.5 倍额外伤害」，与源码一致。

## 调优参考提示

1. **先修 P0-1**：把 `_delayed_magic` 的 `/1.2` 改成 `*1.2`，并把顺序调成「先 `mag_struck_damage` 扣减、后乘 1.2」，条件用「非不死系 且 非玩家」更贴近原版 `Magic.pas:624`；若只想对齐 `RM_DELAYMAGIC` 通用层，则按 `RaceServer >= RC_ANIMAL` 即可。修完法师对怪伤害会明显上升，需同步观察升级速度与药耗。
2. **再修 P0-2**：`_pass_through_magic` 的 `cur_pwr` 改成循环外固定的 `pwr`，每个目标都从原始值算 `round(pwr*1.5)`；否则疾光电影穿透多目标时伤害爆炸。
3. **魔法盾是取舍不是 bug**：要与视频里的官服手感一致，就把公式改成 `15*(lv+1)`（15/30/45/60）；要保持与火炬源码一致则维持现状。改前先明确目标版本。
4. **多宝宝**属于结构性改动（`summon_id: int` → 列表），影响跟随、召回、死亡清理、存档，不建议随数值调整一起做。
5. 第 7 项「浮动 1 点」来自 `Magic.DB` 的 `DefPower/DefMaxPower`，改表即可，不必改代码。
