## 重点摘要

1. **治愈术 / 群体治疗术**：0~3 级基础回复分别为 `4-6 / 7-11 / 10-16 / 14-21` 与 `6-7 / 9-10 / 12-13 / 14-15`；**每点道术 +2 回复**，吃幸运/诅咒；每秒约 5 跳、默认每跳 5 点（约 25 点/秒）；单次回血上限默认 **300 点**，可叠加，后台可调每跳与上限。
2. **施毒术**：绿毒基础伤害 `2 / 2 / 2 / 3`，分别每 `60 / 30 / 15 / 10` 点道术 +1 伤害，约 **2.5 秒一跳**；红毒全等级效果一致，是**使目标受到的伤害 +20%**（不是降防）。
3. **灵魂火符 / 噬血术是主要输出**：基础伤害 `13-16 / 17-22 / 20-29 / 24-35` 与 `18-23 / 22-30 / 25-36 / 29-44`，全等级**额外 96% 道术伤害**；对人 100%，对怪（生物/不死）都只有 **87.5%**。
4. **噬血术回血按未衰减伤害算**：默认回复所造成伤害的 50%；打人 100 回 50，打怪实际只打 88 也回 50。
5. **神圣战甲术 / 幽灵盾**：全等级 +`0-12` 防御或魔防；等级与道术只影响持续时间 `31-32 / 41-42 / 51-52 / 61-62` 秒，每点道术 +1 秒。
6. **精神力战法**：0 级无效，1/2/3 级 +3/+5/+8 准确；只影响物理命中，对火符等技能无效。
7. **道士后期弱的解释**：能吃道术加成的技能太少，多数只影响持续时间，所以后期定位偏辅助/刷图。

## 调优参考提示

- **机制差异优先于数值**：绿毒在 996 下吃道术加伤害、官服只加持续时间，这是版本分叉的典型例子。若项目走原版保真，先查 Delphi 源码，不要照抄 996。
- **输出结构参考**：道士仅灵魂火符/噬血术吃 96% 道术加成，其余多为持续时间类；这解释了"后期弱"的体感。若要调强道士，优先考虑增加可吃道术加成的技能，而不是只调单项数值。
- **PvP/PvE 倍率差**：灵魂火符与噬血术对人 100%、对怪 87.5%；噬血术回血却按未衰减伤害计算——这类"伤害与回血不同口径"是容易漏掉的数值细节。
- **红毒语义**：增伤 20% 与"降防"在服务端是两种完全不同的实现；本项目若已按原版实现降防，不要按视频改成增伤。
- 项目实现索引（仅定位，不代表数值一致）：`pyserver/handlers_combat.py`（治愈/群疗回血、施毒、幽灵盾/战甲、灵魂火符）、`pyserver/autopilot.py`（道士治愈/火符托管）、`pyserver/util.py`（治愈术 GetPower 取整）、`pyserver/world.py`（buff 持续时间）。
