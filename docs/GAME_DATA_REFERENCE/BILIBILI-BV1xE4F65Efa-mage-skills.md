## 重点摘要

1. **雷电术**：0~3 级 `24-31 / 29-43 / 34-55 / 40-67` + 100% 魔法力；对人 100%，**生物系 83%**，**不死系 125%**（比生物系多 50%）。
2. **疾光电影**：`7-8 / 9-10 / 11-12 / 13-14` + **110%** 魔法力；直线最多 **8 个目标**，后一个目标是前一个的 **1.1 倍**，第 8 个约 **195%**；无视距离，但只打一个目标时一般，魔法力 <260 不如 3 级雷电。
3. **地狱雷光**：`12-39 / 15-46 / 18-53 / 20-61` + 100% 魔法力；**对不死系 100%，对人/生物系仅 10%**。
4. **火墙**：`1-2 / 1-2 / 2-3 / 2-3` + 100% 魔法力；基础伤害几乎可忽略，升级主要延长持续时间；持续时间不吃幸运/诅咒。
5. **灭天火**：`34-40 / 45-55 / 56-70 / 66-85` + 100% 魔法力；比雷电基础更高更稳，附加**造成多少伤害就打掉多少蓝**；生物 83% / 不死 125%。
6. **流星火雨**：`25-27 / 30-33 / 35-40 / 40-46` + 100% 魔法力；**打两段**，表中数字 ×2 才是总伤害；生物 83% / 不死 125%。
7. **冰咆哮**：`20-22 / 24-27 / 27-31 / 31-36` + 100% 魔法力；无特殊效果的范围伤害。
8. **魔法盾**：物伤减免 `0% / 15% / 30% / 45%`，魔伤减免 `15% / 30% / 45% / 60%`；升级增加持续时间与承受上限，魔法力也会提升二者；不吃幸运/诅咒。996 可设置为也减免刺杀剑术，**官服刺杀无视魔法盾**。

## 调优参考提示

- **怪物类型倍率是核心口径**：人 100% / 生物 83% / 不死 125%，以及地狱雷光"不死 100%、人/生物 10%"，都是与"基础伤害 + 魔法力加成"相乘的独立层。项目里若只做基础伤害会显著偏强或偏弱。
- **疾光电影的 1.1 累乘来自原版笔误风格的实现**：本项目 `pyserver/handlers_combat.py` 已有 `undeadattack` 累乘注释；视频给出 1.1 倍/目标、8 目标约 195% 可作为量级参考，但取整与目标上限需回原版确认。
- **二段伤害别漏乘**：流星火雨表格数字 ×2 才是总伤，做数值对齐时容易少算一半。
- **PvP 魔法盾口径**：996 可配置成减免刺杀剑术、官服则无视；项目若做 PvP 平衡，先确认目标版本，别按私服配置改。
- 项目实现索引（仅定位，不代表数值一致）：`pyserver/handlers_combat.py`（雷电/疾光穿透与不死加成、火墙、冰咆哮、地狱雷光、魔法盾）、`pyserver/world.py`（魔法伤害结算与魔法盾折减）、`pyserver/autopilot.py`（法师技能优先级 雷电 > 大火球 > 火球）。
