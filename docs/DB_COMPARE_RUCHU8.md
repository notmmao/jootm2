## 1. 数据血统判定 —— 这是四轮以来最干净的参照

**本站数据 = 标准 1.76 官方库数值，逐字未动**。铁证是三方对照（本站 217/312 唯一名 ∩ 本项目 ∩ `176-mir2-red/REDM2.db`）：

| 字段 | 本站=REDM2 | 本地=REDM2 |
|---|---|---|
| Monster HP | **149/149（100%）** | 87/149（58%） |
| Monster Exp | **149/149（100%）** | 2/149（1%） |
| Monster Level | **149/149（100%）** | 123/149（83%） |
| Monster DC/DCMax | 148/149 | 107/149 |
| StdItems DcMin/DcMax | **256/256（100%）** | 253/256 / 250/256 |
| StdItems Weight | 252/256 | 242/256 |

结论链：本站 ≈ REDM2 ≈ **原版 1.76 口径**；本项目 CSV 是在这套标准库上改过的私服库。至此已有 5 套库可交叉验证：

- **Exp 被本地整体放大 3 倍**：本地/本站 median = **3.000**，与 applem2 轮（79 条恰好 3.000）第四次互相印证——这是本项目相对原版最系统性的数值改动。
- 本地少数怪 HP 被调高（剧毒蜘蛛 1200→2800、千年树妖 1800→5000、半兽统领 700→3000，与 ChineseDB 的 1600 僵尸不同方向），Level 99 化（本站/REDM2 都是 50~60，本地拉到 99）。

## 4. 结论（三句话）

1. **ruchu8 站 = 原版 1.76 数值的干净镜像**（与 REDM2 逐字段 100%/99% 一致），是五轮对比里最好的"原版基线"——比 GEEM2/applem2/ChineseDB 这些私服库更适合回答"我们改了什么"。
2. **借它对照能直接量化本项目的私服改动**：Exp 全线 ×3、Boss 怪 HP/Level/AC 强化、Price ×1.82、个别武器攻防微调、NeedLevel 技能书口径缺失。
3. **本站有本地缺的 1.76 正统内容可回补**：牛魔系/暗之系/宝箱怪 65 种怪、荣誉勋章系统 25 件、天尊/法神/圣战套装成品；Mob_*.html 的 219 页**刷怪分布表**（地图×坐标×刷新时间）对照见 §7-§8 第二轮。

## 6. 置信度评估（"把本站当官方 1.76 数据"，2026-11-13 补）

分两个口径回答，结论不同：

| 用途 | 当**标准 1.76 流通数值集** | 当**盛大官方服务器实际数据** |
|---|---|---|
| 怪/物品属性（HP/Exp/DC/持久/重量/需要等级） | **90** | 60 |
| 怪物分部（哪张图刷什么怪） | **80** | 45 |
| 掉落表（1/X 物品集合） | 60 | 35 |
| NPC 分部（每图 NPC 数） | 70 | 40 |
| NPC 商品清单 / 商店价格 | **30** | 15 |
| **综合** | **≈85** | **≈50** |

依据（正/反面都要看）：

- **正**：属性类字段与独立流传库 REDM2 逐字 100%（HP/Exp/Level 149/149、DcMin/DcMax 256/256，§1），说明它不是某私服魔改导出，而是**公开流通的 1.76 标准数值集**；地图/NPC/刷怪结构与本地"我本沉默"私服库对照时，本站呈现的恰是"未被密度魔改"的那一面（§7/§8），与攻略文献一致。
- **反**：盛大官方服务器的 DB 从未公开，任何"官方数据"都只能是流通包推断；**价格列与 REDM2 不一致**（木剑本站 27 vs REDM2 50，是 bk5 自己商店口径）；NPC 数据有手工维护痕迹——商品名里出现 `myzr`、`qfxl` 式拼音占位，quest 物品与商店货混在一张清单（§8 的 b/c 语义）；技能页是 bk5 自己的 4 级体系（§2.3）。
- **使用建议**：数值仲裁（本项目 vs 其他私服谁改了原版）拿本站+REDM2 双基线用，放心；刷怪密度、商店目录、价格只当参考，别当官方真值。

## 7. 怪物分部（Mob_*.html 刷怪表 vs 本地 MonGen.txt）

站点 218 个 Mob 页提取出 **3131 条刷新记录**（`图名（x,y）|数量|刷新时间`，213 唯一怪、120 唯一图名）；本地 MonGen.txt 有效行 2980、238 唯一怪。站点地图中文名→本地图号经 MapInfo.txt（445 条定义）映射：精确 60 + 手工别名 23（兽人古墓→半兽古墓、洞穴→天然洞穴、牛魔寺庙→牛魔寺等版本命名差）+ 相似匹配 24，共 107/120；**未映射 17 个副本区本地整区不存在**（骨魔洞 1-5、尸魔洞 1-3、钳虫巢穴、十八铜人阵、死亡神殿、深渊魔域、虎卫堂、困惑殿堂等——苍月岛/封魔系内容本地没做，与 §3 缺牛魔怪族的结论同源）。

| 指标 | 数值 | 解读 |
|---|---|---|
| 怪物种类集合 | 共有 153 / 仅站 60 / 仅本地 85 | 仅站点全是标准 1.76 怪（宝箱×9、暗之教主×7、恶灵系）；仅本地是 `0/10` 变体+护卫/练功师私服内容 |
| **(图,怪) 分部对** | 站点 950 / 本地 1666 / **共有 578（站点侧 61%）** | 种类×地图的分布结构大体同源 |
| 每图刷怪点数（MapList 列） | 一致 4/99 | 本地密度远超标准：祖玛阁 站点 5 点 vs 本地 569 行、香石墓穴 6/32 |
| 按怪聚合总数量 | 一致 20/149（13%） | 僵尸1 站点 505 vs 本地 709、半兽人 1135 vs 294——**密度被整服重调** |
| 刷新间隔众数 | 一致 57/149（38%） | 僵尸系 标准 8 分 vs 本地 23 分；千年树妖 360 分 vs 60 分 |
| 掉落（Mob 页 vs MonItems.txt） | 共有怪 142，逐字一致仅 2 | 物品集合高度重叠；差异=本地加私服专属爆物（矿区凭证、天外飞石、树妖爆传送戒指/圣战系）+概率改写 |

**结论**：本站刷怪分部 = 1.76 标准版基线可信；本地 MonGen 在"哪张图有什么怪"层面保留约六成原版对，**密度/时间/爆物基本整个是"我本沉默"自己的设计**——这正是之前几轮 DB 报告看不到的维度（属性库不含刷怪）。

## 8. NPC 分部与出售商品（Npcshuju 树 vs MerChant/Npcs/[goods]）

站点 NPC 数据在 `js/npcshuju.js`（npc.html 实际加载它；`npcshuju_2.js` 未被引用），120 条，每条 `{n:名字索引, b:[], c:[]}`。渲染代码（npc.js）确认语义：**b=NPC 消耗的物品（收购）、c=NPC 给予的物品（出售/任务给予）**——两列混着商店货物、quest 道具（介绍信、药剂师的信）、荣誉勋章和 `myzr` 式拼音占位，是人工整理而非服务端导出。

| 指标 | 数值 |
|---|---|
| NPC 名字集合 | 站点 120 / 本地 133（MerChant 251 行+Npcs 52 行去重后）/ **交集 84** |
| **每图 NPC 数（MapList 列 vs 本地按图计数）** | **一致 81/99（82%）**——NPC 分部几乎原版照抄；不同处是 ±1（紫水晶屋 2/1、桃源之门 3/2、祖玛阁/教主之家本地多塞 1 个） |
| 商品目录 | 站点清单商品全集 73 种 ∩ 本地 `[goods]` 目录 143 种 = 24；按"内容最佳匹配"逐 NPC 比对 mean Jaccard 0.11，无一 ≥0.7 |

商品对照失败的原因（不是本地货架全错了）：①站点 c 列混入任务给予物/奖励（武馆教头给荣誉勋章×25——本地没做勋章系统）；②本地大量商店是**对话式收购**（屠夫 1Bme 脚本无 `[goods]` 段，收购肉靠 @sell 对话），两站都无结构化清单可比；③本地 [goods] 价格列（金创药(小量) 100、木剑 10）是私服自定，与站点商店价（×2 显示口径，§0）和 StdItems.Price（×1.82，§2.2）三套数字互不相同。**商店货品集合层面唯一稳定的对照仍是 §2.2 的 StdItems 价格分析；Npcshuju 树只适合当"1.76 有哪些 NPC、开在哪张图"的分布参考。**
