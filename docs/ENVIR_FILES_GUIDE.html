gamedata / Mir200 / Envir — 配置文件说明

传奇 1.76/1.80（GameOfMir）服务端环境目录逐个文件的作用与字段口径。

约定：所有以 ; 或 # 开头的行都是注释，解析时跳过；空行忽略。
文本编码混合 UTF-8 / GBK / UTF-16，由服务端 gamedata.read_lines 按内容自动探测，不要写死编码。
涉及时间的字段，本文一律在含义后标注单位。

一、地图与坐标

MapInfo.txt地图属性总表

登记所有地图的编号、中文名与通行/属性标志。是地图世界的权威清单。

[地图号 地图名] 标志1 标志2 ... [0 比奇省] [0122 皇宫] FIGHT D011 <-> D012 (33,8 -> 3,8) ; 地图连接门(传送)
字段 / 标志说明
地图号与 .map 文件名一致（如 0、0122、D011）。
FIGHT可 PK 区；DARK 无地图光；QUIZ 禁魔法；NOHERO 等按原版语义。
A -> B (x,y -> x,y)地图间连接门：A 图坐标 (x,y) 通到 B 图坐标 (x,y)。坐标为格。
MiniMap.txt小地图编号映射

把地图号映射到客户端 MiniMap.mmp 里的小地图序号，供右上小地图取图。

地图号 小地图序号 D001 1 D011 4

注：客户端按 序号 - 1 索引纹理（1-based 表，0-based 取数）。

StartPoint.txt出生 / 复活点

各地图的安全区与复活坐标。角色死亡后回到所属地图的对应行。

地图号 X Y 0 289 618 0 650 631

X / Y 单位均为地图格。

二、怪物

MonGen.txt刷怪配置（Mon Generator）

全局刷怪表：在哪个地图的哪块区域、刷哪种怪、刷多少只、多久刷一批。

地图号 X Y 怪物名 范围 数量 时间 0137 21 11 练功师 0 1 10 0 665 87 弓箭护卫 0 1 10
列含义单位
地图号 / X / Y刷怪中心点坐标地图格
怪物名须与 mud2/DB/Monster（怪物库）名称匹配—
范围以 (X,Y) 为中心的扩散半径，0=只在这一点格
数量该刷新点一次保持的怪物只数只
时间刷怪间隔（死亡后重刷的周期）。服务端按 间隔 × 60000 毫秒 换算，即 10 → 10 分钟分钟
GuardList.txt地图守卫站位

皇宫 / 土城等固定守卫（卫士、弓箭手）的站列位置。

;名称 区域 X Y dir 卫士 0 275, 212 : 7

X / Y 为格；dir（0–7）为守卫初始朝向（8 方向）。

三、NPC 与商店

Npcs.txt固定 NPC 表（脚本类）

登记非商品的固定 NPC（国王、传送员、任务 NPC 等）在地图上的位置与外观。

名称 代码 地图 X Y 范围 图标 比奇国王 1 0122 29 32 0 8 玛法领路人 ... 3 297 302 0 ...
列说明单位
代码 / 图标对应 NPC 库外观资源号—
地图 / X / YNPC 所在地图与坐标格
范围活动范围格
MerChant.txt商人 / 功能 NPC 表

带脚本交互的商人、修理匠、仓库管理员等 NPC（与 Npcs.txt 同族，走商品/脚本流程）。

;调用文件 地图 X Y 名称 数量 代码 刷新时间 1Bme-屠夫 0102 9 7 屠夫 0 11 0
列说明
调用文件对应 Market_Def/ 下的脚本文件名（含地图后缀）。
数量 / 代码外观代码等，含义同 NPC 库。
刷新时间库存补货周期，分钟（0 = 不自动刷新）。
Market_Def/NPC 脚本 + 货物表目录

每个商人一份脚本，文件名格式 调用名-显示名-地图.txt（如 2Are-铁匠铺老板-0151.txt）。含对话段与 [goods] 卖货清单。

%100 ; 价格倍率(百分比)：Round(单价×1.1)×%100/100 [@main] ; 对话入口标签 <购买/@buy> ... [goods] ; 货物段 物品名 库存 刷新
字段说明单位
%100（脚本头）整体价格倍率百分比，最终售价 = Round(Price×1.1) × 倍率 ÷ 100，与服务端 NpcScriptEngine.goods() 同源。%
[goods] 库存该行货物的存量（第二列是库存，不是价格——常见误区）。个
[goods] 刷新第三列补货周期，分钟。分钟
Npc_Def/对话型 NPC 脚本目录

传送员、任务 NPC 等纯对话脚本，文件名 显示名-地图.txt（如 玛法领路人-3.txt）。用 [@标签] 与 #IF / #ACT / #CALL 等命令驱动。

四、掉落与物品

MonItems/怪物掉落表（每怪一份）

文件名即怪物名（如 僵尸1.txt），内容为该怪被击杀后的掉落规则。

;注释 1/200 基本剑术 ; 概率 1/200 掉「基本剑术」 1/1 金创药(小量) ; 必掉 {1/50} 屠龙 ; {} 表示精英/额外条件掉落
写法说明
1/N掉落概率，每 N 次击杀期望掉 1 次（次为分母，非时间）。
物品名须与物品库（mud2/DB）匹配；缺失定义的原版会跳过。
UnbindList.txt绑定解绑表

定义可通过「解绑卷轴」等操作解除绑定的物品清单。

序号 物品名 100 强效金创药

五、玩家 / 帮会 / 城堡 / 任务

AdminList.txt管理员(GM)名单

每行一个 GM 账号名（* 开头为注释），登录后获得管理权限。

MakeItem.txt合成 / 制造配方

定义用材料合成物品的配方。

[灰色药粉(少量)] ; 成品 食人树叶 4 ; 材料 所需数量(个) 毒蜘蛛牙齿 2
MapQuest.txt地图任务触发表

把地图刷怪点与任务脚本关联：某图某怪被击杀时触发对应 MapQuest_Def/ 脚本。

编号 [地图] 数量 怪物名 物品/标记 任务脚本 12 [401] 1 幻影蜘蛛 * Q1401

任务脚本名对应 MapQuest_Def/Q1401.txt。

MapQuest_Def/任务脚本目录

每个 Q####.txt 是一段任务逻辑脚本（条件、奖励、对话），由 MapQuest.txt 引用。

Startup/登录脚本

StartupQuest.txt：角色每次登录时触发的全局脚本（引导、公告、状态检查等）。以 ;这里是登录脚本 起始。

Castle/沙巴克攻城配置

沙城争夺战数据。Sabuk.txt / SabukW.txt 用 INI 分段（[SetUp] / [Defense] 等）。

[SetUp] CastleName=沙巴克 ChangeDate=2017-2-27 AM 11:05:27 ; 时间戳 WarDate=... ; 攻城日期 [Defense] MainDoorX=672 MainDoorY=330 ; 城门坐标(格) MainDoorHP=10000 ; HP(点) LeftWallHP=5000 ; 城墙耐久(点)
字段说明单位
ChangeDate / WarDate占领 / 攻城日期，格式 年-月-日 AM/PM 时:分:秒时刻(年月日时分秒)
MainDoorX/Y、WallX/Y城门与城墙坐标格
HP城门 / 城墙耐久点

AttackSabukWAll.txt：攻城报名/参与名单。沙巴克配置备份文件.txt：原始配置备份。

GuildBase/帮会基础数据

本目录为空——帮会运行时数据存于数据库（mud2/DB），此处仅保留占位。
